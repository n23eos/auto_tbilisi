# Свободная тренировка по билетам + работа над ошибками

Дата: 2026-08-27
Ветка: `dev`
Статус: согласовано

## Цель

Дать ученику готовиться, а не только проверять себя. Экзамен отвечает на вопрос
«сдам или нет», тренировка — «что я ещё не знаю».

Два режима на одной странице `/bilety/trenirovka/`:

1. **Все билеты подряд** — 870 русских билетов по порядку, без таймера и лимита ошибок.
   Браузер помнит, где ученик остановился и какие билеты уже решены верно.
2. **Работа над ошибками** — только те билеты, где ученик ошибался. Билет уходит
   из списка, когда решён верно.

## Как это работает

- Ответ показывается сразу: верный/неверный, где правильный. Как в экзамене.
- Переход вперёд-назад свободный, ученик может вернуться и перечитать.
- Фильтр: все билеты / нерешённые / мои ошибки.
- Виден прогресс: сколько решено верно из 870.
- Кнопка сброса прогресса — с подтверждением, потому что действие необратимо.

**Ошибки копятся и на экзамене тоже.** Провалил экзамен — ошибочные билеты сразу
попали в «работу над ошибками». Ради этого экзамен тоже пишет в общее хранилище.

## Хранение прогресса

`localStorage` браузера. Ключ `avtoshkola-progress-v1`, внутри:

```json
{ "solved": [1, 2, 5], "mistakes": [17, 22], "position": 12 }
```

- `solved` — билеты, решённые верно;
- `mistakes` — билеты, где ученик ошибся и ещё не исправился;
- `position` — где остановился в режиме «все билеты».

Осознанные ограничения, о них честно сказано на странице: прогресс живёт в одном
браузере, между устройствами не переносится, в приватном окне не сохраняется.
Аккаунтов не заводим — это увело бы в бэкенд, регистрацию и хранение персональных данных
ради задачи, которая решается тремя строчками в localStorage.

`localStorage` может быть недоступен (приватный режим, запрет в настройках) и может
бросать исключение при обращении. Любое чтение и запись обёрнуты так, что при отказе
хранилища тренажёр продолжает работать — просто без запоминания.

## Что проверяем тестами

Логика отделена от DOM, `node --test`, без браузера и без зависимостей:

- чтение прогресса из пустого хранилища даёт пустой прогресс;
- битый JSON в хранилище не роняет тренажёр, а даёт пустой прогресс;
- хранилище, бросающее исключение, не роняет тренажёр;
- верный ответ добавляет билет в решённые и убирает из ошибок;
- неверный ответ добавляет билет в ошибки и НЕ добавляет в решённые;
- исправленная ошибка уходит из списка ошибок;
- функции прогресса не мутируют переданный объект, а возвращают новый;
- фильтр «нерешённые» исключает решённые;
- фильтр «мои ошибки» отдаёт только ошибочные;
- позиция не выходит за границы списка при переходе вперёд с последнего билета
  и назад с первого;
- смена фильтра сбрасывает позицию в начало нового списка;
- билеты с `lang: "ka"` не попадают ни в один список.

## Чего НЕ делаем

- Не заводим аккаунты, сервер и синхронизацию между устройствами.
- Не делаем фильтр по темам: в базе нет поля темы, а выводить её из текста — гадание.
- Не показываем пояснения к билетам: у источника они только на грузинском.
- Не меняем правила экзамена.
