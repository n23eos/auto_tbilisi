# Раздел-тренажёр «Экзамен ПДД» + перевод картинок в WebP

Дата: 2026-08-27
Ветка: `dev`
Статус: согласовано

## Цель

Дать посетителю сайта пройти экзамен по билетам ПДД Грузии по правилам настоящего экзамена,
на русском. Тренажёр должен приводить заявки: после результата — понятный призыв записаться.

Вторая, техническая часть: перевести картинки билетов в WebP, чтобы репозиторий и загрузка
страницы весили втрое меньше.

## Часть 1. Экзамен

### Правила (подтверждены по коду источника, `teoria.on.ge/js/exam.js`)

- 30 вопросов за попытку;
- порог провала у источника — больше 10% ошибок, то есть на 30 вопросах допустимо максимум 3;
- лимит времени 30 минут.

### Поведение

- 30 случайных билетов из 870 русских. Билеты с `lang: "ka"` (51 штука, подкатегория
  «эко-вождение») в выборку не попадают: ученик не должен получить вопрос, который не может
  прочитать. Под тестом — честная сноска, что на реальном экзамене эта тема есть только
  по-грузински.
- Ответ засчитывается сразу: видно, верный он или нет, где правильный, и счётчик ошибок.
- Экзамен заканчивается досрочно на 4-й ошибке или по истечении времени.
- Итог: сдал/не сдал, число ошибок, затраченное время, разбор каждой ошибки
  (вопрос, картинка, что выбрал ученик, что было правильно).
- Кнопки «пройти ещё раз» и «записаться на курс».
- Ничего не сохраняется между заходами: ни прогресс, ни история попыток. Не потому что
  нельзя, а потому что для первой версии не нужно.

### Управление и доступность

- Ответ выбирается мышью/тапом, а также клавишами `1`–`4`; переход дальше — `Enter` или пробел.
- Результат ответа объявляется через `aria-live`, чтобы его услышал скринридер.
- Фокус при переходе к следующему вопросу ставится на заголовок вопроса.

### Данные

Страница грузит существующий `data/tickets-b-ru.json` (91 КБ в gzip) и отбирает `lang === "ru"`
прямо в браузере. Отдельный сборочный шаг и урезанная копия JSON не заводятся: экономия
не окупает второй источник правды, который придётся синхронизировать.

Картинки грузятся по одной, следующая — заранее, чтобы переход не упирался в загрузку.

### Файлы

```
bilety/index.html               — страница экзамена
css/exam.css                    — стили, токены берутся из css/tokens.css
js/exam-logic.js                — чистая логика, без DOM
js/exam.js                      — DOM, таймер, обработчики
js/tests/exam-logic.test.js     — тесты на встроенном node --test
```

Правки в существующих файлах: `index.html` (ссылка в меню и кнопка в блоке обучения),
`sitemap.xml`, `llms.txt`.

### Что именно тестируем

Логика отделена от DOM ровно затем, чтобы её можно было проверить без браузера.
`node --test`, без единой новой зависимости:

- выборка возвращает ровно 30 билетов;
- в выборке нет повторов;
- в выборку не попадает ни один билет с `lang: "ka"`;
- при нехватке русских билетов выборка падает с внятной ошибкой, а не отдаёт меньше 30;
- 3 ошибки — сдал, 4 ошибки — не сдал;
- экзамен, законченный по времени с неотвеченными вопросами, считается несданным;
- 30 верных ответов — сдал;
- формат таймера: 1800 секунд → `30:00`, 65 → `01:05`, 0 → `00:00`;
- проверка ответа сравнивает индекс с полем `correct`.

Разметка и стили проверяются вручную в браузере — скриншотами на десктопе и мобильном.

## Часть 2. WebP

### Замеры (на реальных картинках базы, не оценка)

Все 524 картинки одинаковые — 1006×632, в среднем 128 КБ.

| Вариант | Итог | Выигрыш |
|---|---|---|
| WebP q80, размер не менять | ~29 МБ | 2.3× |
| WebP q82, ширина 900 | ~25 МБ | 2.6× |
| **WebP q82, ширина 800** | **~21 МБ** | **3.1×** |
| WebP q82, ширина 700 | ~17 МБ | 3.9× |

Выбрано: **ширина 800, качество 82**. Проверено глазами на схеме перекрёстка — светофор,
знак «уступи дорогу», разметка и цифры вариантов ответов читаются. 700 не берём: на этих
картинках мелкие дорожные знаки, нечитаемый знак означает неверный ответ ученика.

Отдельно отмечено: изначальная оценка «5–10×» была неверной — эти JPEG уже сжаты,
и сам по себе WebP даёт всего 2.3×. Основной выигрыш даёт уменьшение ширины.

### Как встроено в парсер

Ключевое требование: повторный запуск парсера не должен возвращать всё к JPEG и не должен
заново скачивать картинки.

- скачанные JPEG складываются в кэш `tools/.cache/category-2/images/` (в git не попадает);
- из кэша делается WebP в `data/tickets/images/<хэш>.webp` — только он и лежит в репозитории;
- в JSON у билета путь ведёт на `.webp`;
- уже готовый `.webp` повторно не пересобирается;
- конвертация проверяется декодированием, как и скачивание: не открылось — билет в проблемные,
  база невалидна.

Старые `data/tickets/images/*.jpg` из рабочего дерева удаляются в этом же изменении.

### Оговорка про историю git

Картинки в JPEG уже попали в `main` и на удалённый репозиторий. Удаление их из рабочего
дерева уменьшает свежую выкладку и сайт, но **историю не чистит**: `git clone` по-прежнему
будет тянуть эти 66 МБ.

Полностью убрать их можно только переписыванием истории с принудительным пушем. Это
разрушительная операция для общего репозитория, поэтому по умолчанию её НЕ делаем.
Если размер клона важен — это отдельное решение владельца репозитория.

## Правовая пометка

Публикуется русский перевод вопросов и картинки, сделанные on.ge. На странице ставится
видимая ссылка на источник. Ссылка не заменяет разрешения: условия использования on.ge
стоит проверить, а при необходимости запросить разрешение. Решение публиковать принято
владельцем сайта осознанно.

## Чего НЕ делаем

- Не делаем режим свободной тренировки по всем билетам — это следующий шаг, отдельным спеком.
- Не сохраняем прогресс и историю попыток.
- Не заводим аккаунты, рейтинги, статистику.
- Не трогаем парсер сверх встраивания WebP.
- Не переписываем историю git.
