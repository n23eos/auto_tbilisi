# Проект: avtoshkola.ge

Сайт автошколы на русском языке в Тбилиси плюс тренажёр билетов ПДД и
Telegram-бот приёма заявок. Живой сайт: https://avtoshkola.ge

## Три независимые части

| Часть | Где | Чем запускается |
|---|---|---|
| Сайт и тренажёры | корень, `css/`, `js/`, `bilety/`, `voprosy/` | статика, без сборщика |
| Telegram-бот | `bot/` | Cloudflare Workers + D1 |
| Инструменты данных | `tools/` | Python 3.12+ |

У них разные зависимости и разные наборы тестов. CI гоняет все три
отдельными job'ами (`.github/workflows/ci.yml`) — падение одного не скрывает
состояние остальных.

## Команды

```bash
npm test                              # сайт: логика экзамена и тренировки
cd bot && npm test && npm run typecheck   # бот: 141 тест + типы
.venv/bin/python -m pytest tools -q   # инструменты
```

Перед коммитом должны быть зелёными все три.

Локальный просмотр сайта — `python3 -m http.server`, конфиг для превью лежит
в `.claude/launch.json` (порт 8765).

## Что важно знать до правок

**Логика отделена от DOM намеренно.** `js/exam-logic.js` и
`js/training-logic.js` не трогают DOM и покрыты тестами; `js/exam.js` и
`js/training.js` — только интерфейс. Правило экзамена, вычисление прогресса,
фильтры — в *-logic.js, иначе их нечем проверить.

**Версии в путях к CSS и JS обязательны и должны совпадать между
страницами.** `css/style.css?v=27` — это ручной cache-busting под GitHub
Pages. Меняете файл — поднимаете версию во всех страницах, которые его
подключают. Разъехавшиеся версии уже приводили к тому, что один и тот же
файл лежал в кэше под двумя ключами и качался дважды.

**Даты не пишутся руками.** «Дата обновления» в `llms-full.txt` и `lastmod`
в `sitemap.xml` считаются из git:

```bash
.venv/bin/python tools/build_llms_full.py
.venv/bin/python tools/update_sitemap.py
```

**У бота нет `[vars]` в `wrangler.toml`.** Все настройки — через
`wrangler secret put`, иначе деплой затирает значения из дашборда. Если не
задан хоть один из четырёх секретов, бот отвечает 404 на всё и пишет причину
в `wrangler tail`.

**Схема D1 меняется только миграцией.** SQLite не умеет `ALTER TABLE ADD
CONSTRAINT`, поэтому изменение ограничений — это пересборка таблицы
(см. `bot/migrations/0002_leads_status_check.sql`). Перед накатом на базу с
заявками нужен экспорт.

**Персональные данные учеников живут ограниченное время.** Уборка по крону
затирает телефон, имя, вопрос и chat_id (`bot/src/cleanup.ts`). Добавляя
поле с данными ученика, добавьте его и туда.

**База знаний бота собирается, а не пишется.** `bot/src/generated/kb.ts`
руками не правится — источник в `baza-znaniy/dlya-bota/*.txt`, сборка входит
в `npm run deploy`. Есть тест, который ловит расхождение с `.md`-оригиналами.

## Стиль

Комментарии по-русски и объясняют **почему**, а не что. В этом репозитории
это выдержано последовательно — держитесь той же планки: комментарий
описывает, что сломается без этой строки.

Планы работ лежат в `.plan-*.md` в корне. Известные дефекты данных билетов —
в `docs/tickets-known-issues.md`.
