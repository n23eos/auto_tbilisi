# Чат школы: серверное ядро

## Выпуск 2026-09-14: границы и релевантность

Опубликован как `20260914-answer-quality` по разрешению пользователя. Публичный
API после выпуска проверен: арбузы, заявка, смешанный вопрос; health ok, admin401.
Предыдущий выпуск сохранён, данные и настройки не заменялись. Ниже история проверок кандидата.

Локально добавлены `out_of_scope` (спокойное объяснение компетенции без контакта) и
`enroll` (инструкция записи через телефон/WhatsApp). Смешанный вопрос получает ответ
о школе и объяснение границ. Внешние статусы API сохранены, виджет менять не требуется.
Из поисковых фрагментов удалены служебные указания и фактчек-аннотации, сохранены
клиентские сведения и оговорки. Исходные TXT/Markdown и Telegram не изменены.

После структурной проверки тот же Flash отдельно оценивает соответствие ответа
вопросу и истории. Только строгий enum verdict принимается, свободный текст не
выводится. При отклонении — коррекция; после подтверждённой посторонней темы сбой
коррекции также возвращает границу вместо телефона. Проверка учитывается в общих
лимитах 6 model calls / 8 tools / 30 секунд / 2 коррекции / $5 в месяц. Успешный ответ
обычно требует одного дополнительного API-вызова.
Цены и даты повторно сверяются после review. Trace содержит `reviews`, `action`,
`scope`, `model_calls`, без исходных сообщений.

Поиск сохраняет слова исходного вопроса вместе с переформулировкой модели; лимит
выдачи остаётся 4 фрагмента / 6000 символов. Узкая проверка явно указанной категории
не допускает подмены категории в тематическом ответе, но не заменяет semantic review.

Проверено: 75 тестов chat_agent, 126 tools и 41 сайта; независимое ревью; виджет
в браузере 1280×900 и 375×812, три сценария и Escape, без console errors.
Браузерная проверка использовала fixture-провайдер и реальный harness/HTTP/виджет:
она не доказывает качество понимания настоящей Flash. Отдельно реальная Flash:
14/14 в финальном прогоне изолированного кандидата VPS. Deploy не выполнялся.
Подробности и ограничения: [отчёт](../docs/chat-answer-quality-2026-09-14.md).

Фиксированные реальные проверки (14 синтетических кейсов):

```sh
python -m chat_agent.eval_answers --budget /var/lib/avtoshkola-chat/budget.sqlite3
```

Запуск требует серверного ключа и существующего общего ledger; каталог фактов
создаётся временно из seed, production-прайс не меняется. Это проверка fixture-цен,
а не подтверждение актуального прайса. `--case application` ограничивает повтор
конкретным кейсом. Результаты печатаются как JSONL с ID, ответом, trace и расходами.
При несовпадении runner завершится кодом 1; машинные критерии дополняются чтением
ответов. Проверка моделью вероятностная и не гарантирует отсутствие всех ошибок.

Live-прогон остановлен автоматическим контролем передачи данных: требуется
подтвердить перенос кандидата и KB на VPS и передачу выбранных фрагментов DeepSeek.
Дальнейшая передача должна ограничиваться кодом ядра/eval runner и шестью TXT
`00-o-shkole`, `01-obuchenie`, `02-ceny-i-oplata`, `03-dokumenty-i-dopusk`,
`04-ekzameny`, `05-prava`; файлы 06–09, сводные базы, CSV, заметки и секреты не нужны.

Ниже — история реализации; старые отметки незавершённых этапов сверять с

## Проверенное состояние 2026-09-12

Работают DeepSeek Flash (thinking disabled), bounded tool loop, локальный поиск тематических KB-фрагментов, SQLite-каталог, валидация и рендеринг точных значений. Для общих ответов модель выбирает фрагменты, код выводит их исходный текст: свободный пересказ пока отключён. Это защищает от выдуманного текста, но выбор правильной темы всё ещё требует semantic evals.

Live smoke на VPS: «Можно ли учиться онлайн?» → поиск KB → PASS; два вызова Flash, 2581 ms, консервативная стоимость $0.000781. Ключ загружался systemd из `/etc/avtoshkola-chat.env`, без вывода и копирования на Mac. Прогон выполнялся с DynamicUser и ProtectSystem=strict, без публичного HTTP-порта. Код smoke: `/opt/avtoshkola-chat-smoke`; учёт расходов: `/var/lib/avtoshkola-chat-smoke`. Это не production deployment; постоянный сервис не запущен.

CLI после задания серверного окружения:

```sh
python3 -m chat_agent.cli 'Можно ли учиться онлайн?' --state /path/to/private/state
```

Обязателен `DEEPSEEK_API_KEY`. Модель и отключение thinking зафиксированы в коде; переключение на более дорогую модель не предусмотрено. `.env.example` — справочник, CLI сам файл не читает.

Бюджет резервируется атомарно в SQLite до каждого вызова, максимум $5 в месяц по Asia/Tbilisi. Неоднозначные ошибки сохраняют резерв. Для production использовать ОДНУ постоянную базу бюджета, перенести учёт smoke; удаление/смена базы обнуляет учёт. Лимит не распространяется на других пользователей того же API-ключа. Оценка использует peak/cache-miss ставки; после 2026-10-12 вызовы блокируются до проверки тарифов. Это прикладной ограничитель, не банковский запрет списаний со всего аккаунта.

`http_app.Application` — WSGI API: POST `/api/chat`, GET `/api/catalog`, GET `/health`. Ограничены Origin, тело 20 KB, 6 вопросов/минуту на адрес, 60 суммарно и 4 одновременных запроса на процесс; trace наружу не отдаётся. Адрес посетителя берётся из последнего X-Forwarded-For только при соединении с локального proxy; Gunicorn слушает только loopback. CORS не заменяет защиту от автоматических запросов.

Production-сервис работает на VPS под отдельным пользователем через Gunicorn/systemd; код read-only, состояние закрыто правами 0700, systemd sandbox включён. Публичный временный HTTPS endpoint: `https://vps-apds.tail9c66b0.ts.net:10000`. Он опубликован через Tailscale Funnel без нового входящего порта. Постоянный hostname `chat.avtoshkola.ge` и Cloudflare Access для админки требуют подключения DNS-зоны; до этого `/admin/` fail-closed возвращает 404.

Готов первый срез: SQLite-источник цен/групп, история изменений и защита от затирания параллельных правок; проверка структурированной цены; рендерер точных значений. Модель не имеет доступа к записи каталога. Методы записи пока локальные — HTTP и авторизация ещё не реализованы, публично их не выставлять.

Из корня репозитория:

```sh
.venv/bin/python -m pytest chat_agent/tests -q
.venv/bin/python -m chat_agent.demo
```

Демо использует временную базу и fixture-ответы, не сеть и не платный API. Неправильная цена 200 получает FAIL, исправленная 150 — PASS; только затем печатается ответ. Это демонстрация валидатора, ещё не настоящий цикл коррекции DeepSeek.

Денежные суммы — целые тетри, без float. Изменение требует текущей revision; конфликт возвращает ошибку. Даты проверяются в Asia/Tbilisi. Прошедшая дата не считается ближайшим набором; planned всегда имеет оговорку о возможном переносе. Срок действия прайса задаёт редактор: автоматическое продление не подтверждает актуальность.

Остаются: импорт подтверждённого публичного каталога, semantic evals, production HTTP runner, админка/Access, виджет и публичный deployment. HTTP записи каталога пока нет.
