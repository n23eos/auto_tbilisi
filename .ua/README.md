# Understand Anything: карта avtoshkola.ge

Точка входа для будущего агента: [docs/agent-guide.md](../docs/agent-guide.md).
Обязательные правила остаются в `AGENTS.md` и `CLAUDE.md`.

- `knowledge-graph.json`: файлы, значимые функции и классы, связи, слои и tour.
- `meta.json`: дата анализа и базовый commit. Сверяйте с `git status`:
  совпадение HEAD не гарантирует отсутствие новых незакоммиченных правок.
- `fingerprints.json`: baseline bundled parser для будущего обновления.
- `intermediate/scan-result.json`: сохраненная инвентаризация файлов.
- `validation.json`: проверка покрытия, ссылок и ограничений анализа.
- `config.json`: русский язык, автоматическое обновление выключено.
- `.understandignore`: подтвержденные исключения личных заметок, секретов,
  зависимостей, кэшей и аудио/видео. Тесты и спецификации включены.

Карта строится штатным навыком `understand-anything:understand`. Просмотр
через `understand-anything:understand-dashboard`. Локальный viewer требует
URL с временным token из вывода сервера; не сохраняйте token в репозитории.

Для обновления после commit используйте incremental workflow навыка.
Если поменялся незакоммиченный код при прежнем HEAD, выбирайте полный анализ:
оптимизация по одному commit может считать старую карту актуальной.
При смене правил исключения выполните повторную инвентаризацию.

Покрытие означает наличие узлов для файлов разрешенного состава. Это
не формальная проверка поведения приложения. Импорты и диапазоны символов
извлекаются bundled scripts; динамические вызовы, внешние сервисы и
связи, возникающие только во время исполнения, могут быть неполными.
Изображения представлены как ресурсы без анализа содержимого пикселей.
Встроенные исключения инструмента также действуют: lock-файлы, некоторые
форматы медиа и служебные файлы могут отсутствовать в графе.

Временные материалы анализа локально игнорируются `.ua/.gitignore`.
Постоянные JSON и памятка доступны для сохранения вместе с проектом;
создание карты само по себе не выполняет commit, push или deploy.

Viewer сравнивает Git commit и рабочую копию. После построения карты он
может показывать dirty-warning для измененных `.plan.md`, `AGENTS.md` и
новой памятки, даже когда эти файлы уже включены в текущий анализ.
Подтвержденный состав и результат проверки смотрите в `validation.json`,
контентный baseline в `fingerprints.json`, а состояние рабочей копии
проверяйте через git. Предупреждение не скрывалось изменением commit hash.
