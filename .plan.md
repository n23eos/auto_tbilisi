## План: сниппет в поисковой выдаче (27.08.2026)

**Проблема.** В выдаче Google вместо meta description показан список контактов
из нижней секции страницы. Дополнительно установлено: в индексе лежит версия
страницы до последних правок (в сниппете текст «как добраться», которого в
HTML уже нет).

**Ограничение.** Сниппет выбирает Google. Description — рекомендация, а не
команда. Гарантировать конкретный текст в выдаче невозможно, можно только
устранить причины, по которым Google его отвергает.

### Шаги

1. Переписать `<meta name="description">` → verify: длина 140-160 символов,
   без призыва к действию, описывает содержимое страницы.
2. Добавить содержательный абзац в первый экран под h1 → verify: текст виден
   в HTML до первой секции с анимацией.
3. Страховка от скрытого текста: показывать все `[data-reveal]` через 3 с
   после загрузки, если IntersectionObserver не сработал → verify: в консоли
   `document.querySelectorAll('[data-reveal]:not(.is-visible)').length` === 0
   без прокрутки.
4. Запросить переобход в Search Console → verify: в выдаче обновлённый текст.

Шаг 4 выполняет пользователь — нужен доступ к аккаунту Google.
