# AGENTS.md — avtoshkola.ge

Перед любой работой прочитай `CLAUDE.md`: это основной источник архитектурных
правил, команд проверки и ограничений по данным. Все правила из него обязательны
и для Codex.

## Адаптация для Codex

- Упоминания Claude Code означают текущего coding-agent, если речь не идёт о
  конкретном продукте или файле.
- `.claude/launch.json` используй только как справочник порта; UI проверяй через
  доступный браузер Codex или готовый runner проекта.
- Не имитируй отсутствующие slash-команды и инструменты: запускай реальные
  команды, перечисленные в проекте.
- При конфликте механики работы этот файл имеет приоритет; архитектурные,
  защитные и проверочные правила `CLAUDE.md` сохраняют силу.
