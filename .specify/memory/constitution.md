# Конституция avtoshkola.ge

Версия 1.0.0, принята 2026-09-12.

1. Сохраняем архитектуру: статический HTML/CSS/JS, отдельный Telegram Worker с D1 и Python-инструменты. Spec Kit описывает новые изменения, не требует переписывать сайт.
2. AGENTS.md и CLAUDE.md обязательны. Чужие изменения сохраняются. Личные !notes игнорируются через `\!notes/`, не публикуются.
3. Модель не создаёт цены, даты и подтверждения записи. Соответствие источнику и актуальность источника проверяются отдельно.
4. Доменная логика отделена от UI и API. Содержательные тесты и фиксированные evals работают без сети; live-проверки отмечаются отдельно.
5. Секреты остаются на сервере; логи не содержат ключи и исходные пользовательские сообщения по умолчанию. Число вызовов, время и размер контекста ограничены.
6. Проверка до выдачи ответа обязательна. Неопределённость приводит к уточнению или контакту школы; отправка заявки не заявляется без фактической отправки.

## Проверки и управление

Команды проекта: npm test; в bot/ — npm test и npm run typecheck; .venv/bin/python -m pytest tools -q. Перед коммитом обязательны все три. Новая часть получает собственные pytest и evals. UI проверяется в браузере, включая мобильный размер и клавиатуру. Cache-busting соблюдается по CLAUDE.md.

Изменения правил документируются с версией и причиной. Спецификация задаёт поведение, план — решения, tasks.md — ход реализации. Публикация и расходы требуют соответствующего разрешения пользователя.
