# Проверка интерфейса

Установка и запуск:

```sh
npm ci
npx playwright install chromium
npm run test:browser
```

Runner сам поднимает статический сервер на 127.0.0.1:8881 и завершает его после проверки. Порт должен быть свободен. Ручной просмотр сайта может работать независимо на другом порту.

Сценарии выполняются в отдельных контекстах Chromium на 1280x900, 390x844 и 320x780. Хранилище тестов не затрагивает браузер пользователя. Внешние запросы подменены: каталог цен отдаёт пустой набор, сторонние ресурсы пустой ответ, реальные заявки и аналитика не отправляются.

Проверяются первый экран и меню, ошибки пустой формы, ручное открытие чата и фокус, поиск среди 921 вопроса, ответ и восстановление тренировки, навигация и избранное в свёрнутых панелях, остановка экзамена после шестой ошибки. В тесте чата намеренно выдерживается прежняя задержка автопоказа 10 секунд.

При ошибке снимок экрана и trace сохраняются в test-results (не отслеживается Git). Этот набор дополняет `npm test`, тесты бота и Python. Он не проверяет внешний API, настоящую доставку заявки, полевые метрики скорости и внешний официальный банк вопросов. Шрифты и видео нужно дополнительно осматривать в обычном браузере.
