# План реализации

Стек прежний: статический HTML/CSS/ES modules, Node-тесты, отдельные бот и Python-инструменты. Новые зависимости не нужны.

1. Вынести запрос каталога в js/chat-api.js. AbortController и finally ограничивают всё чтение ответа, включая JSON; UI оставляет существующий fallback.
2. Создать уменьшенный WebP из исходного PNG. Использовать новый путь и назначать src при открытии, сохранив размеры элемента.
   Мобильную панель привязать к обоим краям viewport через fixed и width: auto, чтобы полоса прокрутки не обрезала левый край.
3. Добавить версии answer-marking.js в обоих потребителях и поднять версии изменённых entrypoints на всех страницах.
4. Проверить таймаут заголовков и тела ответа, успех, ошибку HTTP/JSON и очистку таймера. Проверить версии локальных ресурсов по графу HTML и импортов.
5. Запустить проверки сайта, бота и инструментов. В локальном браузере проверить чат, предупреждение при зависании каталога, ответ и восстановление тренировки, старт экзамена.

Риски: чрезмерное сжатие аватара и забытый импорт при ручном cache-busting. Контроль: осмотр аватара и автоматическая проверка ссылок.
Миграции данных, новые библиотеки и изменение размещения блоков не нужны.

## Результат и проверки, 2026-09-26

Готово локально. Аватар 132x132 WebP занимает 2168 байт вместо 1235240 байт, отображается 44x44 и загружается при первом открытии чата. Исходник PNG сохранён. Команда подготовки: `cwebp -resize 132 132 -q 85 -metadata none images/chat-robot.png -o images/chat-robot-132.webp`.

Каталог цен ограничен 10 секундами, включая чтение тела. Версии chat.js/chat.css обновлены до 4, exam.js до 29, training.js до 12, answer-marking.js подключается с v=1. Добавлены 6 регрессионных тестов. Исправлено обнаруженное обрезание панели чата на узком экране с полосой прокрутки.

Проверки: 82 теста сайта, 141 тест бота, typecheck и 138 Python-тестов прошли. После исправления CSS тесты сайта повторены, 82/82. В браузере проверены главная и FAQ, загрузка аватара только после открытия, Escape и возврат фокуса, экраны 320/390/1280, ответ и переход в тренировке, восстановление вопроса 2 из 20, запуск и ответ в экзамене. В локальной имитации зависшего каталога появилось предупреждение, исходная цена осталась видимой. Ошибок и предупреждений консоли на проверенном пути нет.

Внешний API каталога был заменён только в ответах временного тестового сервера, файлы сайта сохраняют прежний адрес API. Реальные заявки и сообщения не отправлялись. Lighthouse и полевые метрики не измерялись. Commit, push и deploy не выполнялись.
