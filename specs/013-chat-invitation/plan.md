# План автоматического открытия чата

Дата изменения: 2026-10-10. Существующий Spec Kit, feature-directory независим от ветки. Стек: статические ES modules/CSS, Playwright 1.63.0, Node tests. Новые зависимости не нужны.

1. Заменить 30-секундное приглашение немедленным открытием существующей панели на страницах, где подключён чат.
2. Не фокусировать ввод при автооткрытии; сохранить фокус при ручном открытии.
3. Записывать подавление автооткрытия после закрытия в существующий сессионный ключ.
4. Удалить invite DOM, таймер, аналитику приглашения и неиспользуемые стили.
5. Повысить версии chat.js и chat.css во всех HTML-подключениях.
6. Проверить новый контракт в Playwright и выполнить npm test; CUA выполняет главный агент.

Конституция соблюдается: сервер, факты и запись не меняются; автооткрытие не расходует API; !notes игнорируется. Без commit/push/deploy.
