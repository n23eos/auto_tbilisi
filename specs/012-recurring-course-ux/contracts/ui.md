# UIконтракт

## Главная

#prices сохраняет внешний адрес. Три карточки и расчет используют опубликованные data-price-service. Теория ведет #groups, практика/полныйкурс в консультацию напрямую. #prices-table сохраняет доступ к подробному прайсу.

Калькулятор: theory selector,ground/city0..100,optional medical/first exams. Итоги школа/дополнительное/всего, неизвестная выбранная сумма означает «Уточните цену». Изменения без запросов или отправки персональных данных.
