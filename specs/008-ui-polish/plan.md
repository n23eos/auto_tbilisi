# План реализации

Этап: завершено локально, все изменения проверены.

1. Главная и чат: расположение первого экрана, компактные купоны, ручное открытие чата.
2. Тренировка: приоритет продолжения, компактные настройки и навигация во время занятия.
3. Общий DOM-рендерер ответов, индекс прогресса каталога, согласованная навигация и версии ресурсов.
4. Браузерные регрессии и CI, ручная проверка интерфейса на 320/390/1280 px.
5. Итоговое ревью, обязательные проверки, обновление статуса.

Решения: сохранить существующие HTML/CSS/JS, зависимости браузерных тестов только для разработки, внешние API в тестах подменять. Порционную отрисовку каталога вводить только при подтверждённой необходимости.

Владение файлами: помощник главной меняет index.html, css/style.css, css/partner.css, js/chat.js, css/chat.css. Помощник тренировки меняет bilety/trenirovka/index.html, js/training.js, css/exam.css. Основной агент меняет остальные файлы, затем последовательно обновляет общие версии и навигацию.

Проверки: 84 Node, 141 тест бота и typecheck, 138 Python, 18 браузерных сценариев. Независимое ревью завершено, замечания закрыты. Ручной осмотр: главная 1280/320, тренировка 1280/390, продолжение, ответы, увеличение рисунка и фокус.

Блокеров нет. Следующий шаг: просмотр владельцем на http://127.0.0.1:8879/. Публикация не выполнялась. Внешние API, полевые метрики и реальная доставка заявок не проверялись.
