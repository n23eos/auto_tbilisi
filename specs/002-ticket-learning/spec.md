# Feature Specification: Поиск и обучение по билетам

**Created**: 2026-09-24
**Status**: Accepted for implementation
**Input**: Пользователь разрешил сверить банк с teoria.on.ge и улучшить раздел билетов.

## User Scenarios & Testing

### User Story 1 - Понятный состав банка (Priority: P1)

Ученик видит число доступных русских вопросов и ограничения полноты.
Проверка: количество совпадает с доступными вопросами; утверждения об официальном
статусе не выдаются за подтверждённые без сверки с официальным банком.

### User Story 2 - Найти и сохранить вопрос (Priority: P1)

Ученик ищет по номеру или словам, сохраняет билет в избранное и возвращается к нему.
Проверка: поиск номера 1 не возвращает 10; избранное сохраняется после перезагрузки;
поиск без результатов позволяет сбросить условия; прежний прогресс остаётся.

### User Story 3 - Учиться по темам (Priority: P2)

Ученик выбирает тему и короткую сессию на 10 или 20 вопросов.
Проверка: вопросы соответствуют теме источника; счётчик не включает скрытые вопросы;
набор не перестраивается после каждого ответа; для пустой темы есть объяснение.

### User Story 4 - Разобрать схему (Priority: P2)

Ученик увеличивает картинку, закрывает её клавишей Escape, сохраняет ссылку
на вопрос и может перейти к преподавателю с номером вопроса.
Проверка: закрытие возвращает фокус, клавиши ответа не срабатывают в поиске или увеличении.

### Edge Cases

- Недоступное хранилище не мешает отвечать, но показывает предупреждение.
- Старый прогресс и скрытые ID не завышают процент решённых.
- Недоступные темы не блокируют основную базу.
- Ошибки и избранное не исчезают из текущей сессии посреди ответа.
- В экзамене можно отложить вопрос и вернуться; просмотр отвеченного вопроса
  не начисляет ответ повторно. Все 30 ответов, шестая ошибка или истечение времени
  завершают попытку по действующим правилам тренажёра.

## Requirements

- FR-001: Сохранить имеющиеся ежедневные сессии, ошибки и экзамен.
- FR-002: Добавить поиск, избранное, темы с числом доступных вопросов и размер сессии.
- FR-003: Добавить увеличение схемы и постоянную ссылку на билет.
- FR-004: Указать ограничения базы рядом с её размером, убрать неподтверждённые обещания полноты.
- FR-005: Привязку тем получать из исходного каталога, не угадывать по тексту.
- FR-006: Не изменять правильные ответы и не создавать непроверенные объяснения ПДД.
- FR-007: Добавить навигацию и откладывание вопросов в экзамене, сохранив таймер
  и подсчёт только уникальных ответов.

### Key Entities

- Билет: ID источника, язык, вопрос, ответы, изображение, доступность.
- Тема: название, набор ID и источник сверки.
- Прогресс: ответы, повторения, избранные билеты.

## Success Criteria

- SC-001: Билет находится по точному номеру и открывается по постоянной ссылке.
- SC-002: Избранное и прежние ответы сохраняются после обновления страницы.
- SC-003: Все доступные вопросы имеют проверенную привязку к теме.
- SC-004: Основные сценарии работают с клавиатурой и на экране 390 пикселей без горизонтального переполнения.
- SC-005: Ученик видит объяснение разницы между размером источника и доступной тренировкой.

## Assumptions

Сайт остаётся без регистрации. До доступа к актуальному официальному банку
не заявляем полную сверку 898 вопросов. Перевод эко-вождения и содержательные
объяснения требуют проверенного источника или редакционной проверки преподавателем.
