# План реализации

Дата: 2026-09-24. Стек: существующая статика HTML/CSS/JS и Python-инструменты.

1. Проверить источник, сохранить воспроизводимый аудит количества и тем.
2. Расширить training-logic: поиск, избранное, темы, размер сессии, обратная совместимость.
3. Обновить UI тренировки, увеличение картинки, ссылки и честный текст о составе.
4. Проверить регрессии, браузер desktop/mobile, diff и версии ресурсов.

Данные вопросов не переписывать. Темы хранить отдельно с источником и датой.
При ошибке загрузки тем тренировка работает без фильтра темы.
Безопасность: текст только textContent, ссылки на источник проверяются.
Публикация не выполняется автоматически из общего разрешения на работу.
