## Выбранное размещение

Python-сервис + SQLite в отдельном каталоге, отдельное окружение и отдельный непривилегированный service account. Управление через systemd, автоматический старт и ограниченная ротация логов; зависимости не устанавливать в системный Python. Копия SQLite должна делаться согласованным backup-механизмом, а не копированием активного файла без WAL. Локально слушать отдельный свободный порт, проверив его повторно перед запуском.

TLS/публичный маршрут определить после инспекции владельца 443 и DNS: не занимать этот порт вслепую. Tailscale обеспечивает административный доступ, не делает публичный API доступным посетителям сайта. Access должен закрывать административный hostname и backend, а публичный API — обслуживать только разрешённое чтение/чат. Домен сейчас вне Cloudflare; вариант его подключения ещё не выбран.

Свободной RAM достаточно для небольшого Python-сервиса без локальной LLM. Низкий запас диска требует лимита логов/резервных копий перед production запуском; чужие данные не удалять. DeepSeek вызывается удалённо, веса модели не скачиваются. Конфигурация сервиса и приложение пока не установлены.
