# Администрирование цен и групп

Согласовано пользователем 2026-09-12: admin.avtoshkola.ge, вход Cloudflare Access по одноразовому коду на три точных email из admin-access-policy.json. Файл является заготовкой политики, не доказательством настройки сервиса. Все три адреса имеют роль редактора цен/групп, не администратора Cloudflare.

## Требования

- Закрыть весь административный hostname, включая API. Разрешены только три точных email, без правила на весь gmail.com и без альтернативного Include «любой OTP».
- Настроить провайдер One-time PIN на приложении. Проверять Access JWT на backend: подпись через доверенный JWKS, issuer, audience, expiry и email. Не доверять одному заголовку email. Нет конфигурации/валидного JWT — отказ.
- Прямой origin, workers.dev и preview не должны обходить защиту. Изменения принимаются только авторизованным API с проверкой Origin/CSRF, JSON-схемы и версии записи.
- Два раздела: цены (услуга, сумма, валюта, единица оплаты) и группы (формат, дата/время Asia/Tbilisi, статус набора). Сохранение атомарное, конфликт параллельных изменений не затирает чужие данные.
- Единая база для бота и публичных цен сайта. Следующий запрос после успешного сохранения читает новое значение; клиент и API не используют устаревший кеш. История: кто/когда/до/после, восстановление через новую ревизию.
- Прошедшая дата не выдаётся как ближайшая группа. Неизвестная дата не означает отсутствие мест. Прайс не дублируется в поисковых фрагментах KB.
- Проверки: отказ анонимному/чужому email, просроченный или поддельный JWT, неверный audience, прямой origin, CSRF, запись редактором, конфликт ревизий, обновление чтения ботом/сайтом, откат.
