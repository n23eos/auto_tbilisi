# План

Статический HTML сайта, отдельный css/partner.css с версией в URL. Без зависимостей и изменений тренажёра.

1. Изучить активный договор и ограничения Holafly.
2. Подготовить баннер и Facebook-пост, проверить заявленные свойства.
3. Проверить локальный UI и ссылку. Пост сохранить только как черновик, по уточнению пользователя.
4. Зафиксировать результат в карточке проекта.

Решение: первый тест на существующем органическом трафике. До измерений дохода и конверсии не покупать трафик.
Проверки: npm test, браузер desktop и 320/390 px, diff.
Facebook не публиковать: прямое уточнение владельца 2026-09-24.
Проверен код HOLAAVTO: страница Holafly после перехода показывает скидку 5% на следующую покупку eSIM направления. Метки subId1/subId2 разделяют каналы в Impact.

Проверено 2026-09-24: 54 теста сайта, 141 тест бота и typecheck, 131 тест инструментов. Генератор sitemap исправил устаревшие даты после предыдущего коммита тренажёра. В браузере осмотрены desktop и 320 CSS px, границы 649/768 px; баннер не перекрывает hero. Реальная кнопка открывает Holafly с HOLAAVTO. В логе только сторонняя ошибка расширения MetaMask. Один проверочный переход выполнен с боевой меткой home-banner, учитывать при первом анализе.

Обновление 2026-09-24 по отзыву владельца: более выразительная карточка с иконкой eSIM, отдельным блоком скидки и тёмной кнопкой. Раскрытие сокращено до «Партнёрская ссылка · получаем комиссию», 11 px, контрастный текст. Основание: пункт 7.1.3 прочитанных условий Holafly требует ясно раскрывать комиссию; одно техническое rel=sponsored не заменяет видимый текст. Баннер переведён в поток для защиты от перекрытий при масштабировании.

Новый дизайн проверен в браузере на desktop и 320 CSS px: переполнения нет, подпись 11 px, hero ниже баннера. Повторно прошли 54 теста сайта, 141 тест бота и typecheck, 131 тест инструментов.

Обновление 2026-09-24 по запросу владельца: баннер оформлен как отрывной билет. Справа на desktop и снизу на mobile есть отдельный корешок со скидкой и кнопкой, пунктирная линия отрыва и прозрачные круглые вырезы. Проверены desktop и mobile 320 CSS px, сохранена читаемая подпись о комиссии и доступность кнопки. Версия partner.css повышена до 3.
