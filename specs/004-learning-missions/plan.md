# Implementation Plan: Учебные миссии

Дата: 2026-09-24. Спецификация: spec.md.

## Summary
Развить существующие тренировки: стабильная сессия первых ответов, короткая обратная связь, экран результата, награда за отложенное исправление.

## Technical Context
Статические HTML/CSS/ES modules, без новых зависимостей. Сохранение localStorage v1 с необязательными новыми полями. Чистая логика в training-logic.js, UI в training.js. HTML тренировки и общий exam.css. Ссылки cache-busting обновляются согласованно.

## Constitution Check
Архитектура сохранена; исходные данные, цены и объяснения не меняются. Личные заметки игнорируются. Аналитика содержит только агрегаты и режим, без ответов и текста. Публикация отдельно.

## Decisions
Состав миссии фиксирован. Назад показывает уже выбранный ответ. Первый ответ определяет итог. Пропуски доступны для отдельного повторения. Награда требует >=24h после последнего ответа на вопрос с прошлой ошибкой; новая ошибка начинает новый цикл. Быстрые повторения не продвигают интервалы. Короткая CSS-анимация с reduced-motion. Отдельный логический модуль/новая библиотека не нужны.

## Validation
Node tests: миграция, граница времени, повторные награды, первые ответы, пропуски. UI: реальный локальный банк, первая/последняя карточка, возврат назад, итоги, повтор, мобильный экран, клавиатура, консоль. Затем обязательные проверки проекта и diff.
