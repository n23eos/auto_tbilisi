# План реализации

Статический сайт, существующие JSON и темы. Логику валидации и хранения снимка вынести в отдельный модуль с тестами. UI тренировки восстанавливает исходную сессию без markAnswer при загрузке; прямые ссылки имеют приоритет. Тематические страницы генерировать из JSON в статический HTML; не добавлять неподтверждённые объяснения ПДД. Общая шапка со сплошным фоном, мобильными видимыми ссылками и акцентной кнопкой билетов. Версии ресурсов обновить во всех потребителях.

Порядок: спецификация -> параллельно сессия/темы/шапка -> интеграция ссылок и версий -> тесты всех частей -> UI 320/1280 и независимое ревью -> итог и обновление карточки проекта. Публикация по принятому в текущем диалоге разрешению на завершение commit/push.

Проверка 2026-09-25: 74 теста сайта, 141 тест бота и typecheck, 138 Python-тестов прошли. В браузере: каталог и главная на 320/650/768/1280, восстановление позиции/ответа темы 20 после reload и через каталог. Помощник проверил все три темы на 320/1280, отсутствие битых изображений и ошибок консоли. Независимое ревью продолжается; перед публикацией закрыть приоритет прямых параметров и устаревшую карточку продолжения при начале новой сессии.

Финальная проверка: четыре замечания ревью исправлены и перепроверены. Сайт 76/76; бот 141/141 + типы; Python 138/138. В браузере подтверждены приоритет ticket=337 над resume=1, закрытие старой карточки после начала новой подборки и счётчик перекрёстков 15 внутри билета 1. Независимое повторное ревью без замечаний.
